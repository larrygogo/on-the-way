# 地图系统

## 概述

地图系统负责游戏世界的坐标系统、相机跟随、地面渲染和深度排序。这是整个游戏的基础渲染框架。

## 核心组件

### 1. 坐标系统
- **世界坐标**: `(x, y, z)`
  - `x`: 左右推进（横向卷轴方向）
  - `y`: 上下走位（深度轴）
  - `z`: 暂时不用（保留字段）
- **屏幕映射**: `sx = x - cameraX`, `sy = y - cameraY`
- **深度排序**: 使用 `y` 作为 depthKey，越靠下（y 值大）的实体越在前

### 2. 相机系统 (Camera.ts)
- **横向卷轴**: 相机主要跟随玩家 x（横向卷轴）
- **屏幕中心**: 玩家始终在屏幕中心（x 方向）
- **y 跟随**: y 可固定或轻微跟随
- **核心方法**:
  - `worldToScreen(x, y, z)` - 将世界坐标转换为屏幕坐标
  - `follow(x, y)` - 设置跟随目标
  - `update()` - 更新相机位置

### 3. 地面带系统 (GroundBand.ts)
- **可走区域**: 矩形区域（宽 2000，高 400，从 y=200 开始）
- **边界线**: 显示上边界线和下边界线
- **扁平风格**: 深灰色地面，灰色边界线
- **WalkRect**: 提供 `getWalkRect()` 方法，返回可走区域矩形

### 4. 渲染器 (Renderer.ts)
- **DPR 自适应**: 检测 `window.devicePixelRatio`，自动缩放 Canvas 尺寸
- **深度排序**: 按 y 值从小到大排序
  - 值小的先绘制（在后面）
  - 值大的后绘制（在前面）
  - 实现遮挡效果：越靠下（y 值大）的实体越在前
- **Canvas 管理**: 管理 Canvas 上下文，处理窗口大小变化

### 5. Renderable 接口
- **目的**: 所有需要在屏幕上渲染的对象都应实现此接口
- **方法**:
  - `getDepthKey()` - 获取深度键，用于排序渲染顺序
  - `render(ctx, camera)` - 渲染对象

## 核心函数位置

### worldToScreen()
**位置**: `src/game/Camera.ts` (约第 47-51 行)
```typescript
worldToScreen(x: number, y: number, z: number = 0): { sx: number; sy: number } {
  return {
    sx: x - this.cameraX,
    sy: y - this.cameraY
  };
}
```
- 将世界坐标转换为屏幕坐标
- `sx = x - cameraX`
- `sy = y - cameraY`

### camera update()
**位置**: `src/game/Camera.ts` (约第 36-46 行)
```typescript
update(): void {
  if (this.followX) {
    this.cameraX = this.followX - this.screenCenterX;
  }
  if (this.followY) {
    this.cameraY = this.followY - this.screenCenterY;
  }
}
```
- 更新相机位置
- 主要跟随玩家 x（横向卷轴）
- y 可固定或轻微跟随

### render() - 排序和绘制
**位置**: `src/game/Renderer.ts` (约第 81-93 行)
```typescript
render(renderables: Renderable[], camera: Camera, debugDraw: boolean = false): void {
  // 按深度键排序（从小到大，y + sortOffset 值小的先绘制，值大的后绘制，实现遮挡）
  const sorted = [...renderables].sort((a, b) => a.getDepthKey() - b.getDepthKey());
  
  // 清空画布
  this.clear();
  
  // 依次渲染
  for (const renderable of sorted) {
    renderable.render(this.ctx, camera);
  }
}
```
- 按 y 值从小到大排序
- 越靠下（y 值大）的实体越后绘制，实现遮挡效果
- 依次渲染所有实体

## 技术细节

- **坐标系统**: 世界坐标 `(x, y, z)`，z 暂时不用（保留字段）
- **屏幕映射**: `sx = x - cameraX`, `sy = y - cameraY`
- **深度排序**: 使用 `y` 作为 depthKey，越靠下越在前
- **横向卷轴**: 相机主要跟随玩家 x，实现左右卷动
- **DPR 自适应**: 检测 `window.devicePixelRatio`，自动缩放 Canvas 尺寸
- **移动平滑**: 使用速度和时间差实现平滑移动（速度：2.5 单位/帧）
- **移动限制**: 玩家位置限制在 walkRect 内（clamp）

## 注意事项

- 这是横向卷轴风格的 2.5D 实现，不是等距投影
- 深度排序基于 y 值，不是 x+y
- 相机主要跟随 x 方向，实现横向卷轴效果
- `Renderable` 接口为后续扩展预留，便于添加怪物、物品等实体
- 所有实体都应实现 `Renderable` 接口，并正确实现 `getDepthKey()` 方法
