# 拾取与背包系统

## 概述

拾取与背包系统负责物品的拾取、丢弃、存储和管理，包括安全区和普通区的容量管理。

## 核心组件

### 1. 物品系统 (Item.ts)
- **ItemType**: 只有两种：POTION(size=1) 和 EQUIPMENT(size=2)
- **ItemInstance**: 带唯一 id 的物品实例
- **GroundLoot**: 地面掉落实体，包含 item 与世界坐标 pos(x,y)，参与渲染和 y 排序

### 2. 储物袋系统 (Bag.ts)
- **容量**: safeCap=2, unsafeCap=8
- **拾取默认**: 进入 unsafe（普通区）
- **核心方法**:
  - `usedSafe()`, `usedUnsafe()` - 查询已使用容量
  - `canAddSafe()`, `canAddUnsafe()` - 检查是否可以添加
  - `addSafe()`, `addUnsafe()` - 添加物品
  - `dropFromSafe()`, `dropFromUnsafe()` - 丢弃物品
  - `moveSafeToUnsafe()`, `moveUnsafeToSafe()` - 移动物品

### 3. 交互拾取
- **拾取范围**: 距离<=pickupRadius=28
- **HUD 提示**: 显示"按 E 拾取：<name>(占格x)"
- **拾取逻辑**:
  - 若普通区放得下：拾取成功（从地面移除，加入 bag.unsafe）
  - 若放不下：弹出取舍弹窗

### 4. 背包管理系统
- **UI 模式状态**:
  - `uiMode`: "GAME" | "INVENTORY"
  - 按 I 或 Tab 切换背包打开/关闭
  - INVENTORY 模式时：禁用玩家移动/攻击/拾取输入（只允许 UI 操作）
  - HUD 仍显示占用信息
- **背包面板（两栏）**:
  - 左栏：安全区列表
    - 显示 used/cap
    - 每个物品按钮：①移到普通区（免费）②丢弃
  - 右栏：普通区列表
    - 显示 used/cap
    - 每个物品按钮：①移到安全区（需要灵气+读条）②丢弃
- **丢弃规则**:
  - 安全区/普通区都可丢弃
  - 丢弃后在玩家脚边生成 GroundLoot（带轻微随机偏移），并从背包移除
  - 生成的 GroundLoot 可再次拾取

## 核心函数位置

### findNearestLoot()
**位置**: `src/game/Game.ts` (约第 514 行)
- 每帧查找玩家最近的可拾取物（距离<=pickupRadius=28）

### tryPickup()
**位置**: `src/game/Game.ts` (约第 720 行)
- 尝试拾取物品：能放下就拾取，放不下就弹出取舍弹窗

### bagUsed/canAdd/add/drop
**位置**: `src/game/Bag.ts`
- 储物袋的核心函数：查询容量、检查是否可以添加、添加物品、丢弃物品

### spawnGroundLoot()
**位置**: `src/game/Game.ts` (约第 790 行)
- 生成地面掉落物：丢弃的物品生成新的 GroundLoot 掉在玩家脚边

### uiMode 切换
**位置**: `src/game/Game.ts` (约第 177-211 行)
- 切换背包打开/关闭（I 或 Tab）
- INVENTORY 模式下的输入禁用

### 物品移动和丢弃
**位置**: `src/game/Game.ts` (约第 330-482 行)
- `handleMoveSafeToUnsafe()` - 从安全区移动到普通区
- `handleMoveUnsafeToSafe()` - 从普通区移动到安全区（需要灵气+读条）
- `handleDropFromSafe()` - 从安全区丢弃
- `handleDropFromUnsafe()` - 从普通区丢弃

2. 测试拾取：

   - 按 E 键拾取物品
   - 观察 HUD 中的背包容量变化
3. 测试取舍弹窗：
   - 拾取物品直到背包满（普通区 8 格）
   - 尝试拾取新物品，应该弹出取舍弹窗
   - 按 A 键丢弃新物品，物品应该掉在脚边
   - 按 B 键打开背包取舍
4. 测试背包管理：
   - 按 I 键打开背包
   - 查看两栏布局和物品列表
   - 点击安全区物品的"移到普通区"按钮
   - 点击丢弃按钮，观察物品是否掉在玩家脚边
   - 关闭背包，按 E 拾取掉落的物品

## 按键说明

- **W/A/S/D**: 移动玩家
- **E**: 拾取物品（靠近掉落物时，仅在 GAME 模式下）
- **I/Tab**: 打开/关闭背包
- **A**: 在取舍弹窗中丢弃新物品
- **B**: 在取舍弹窗中打开背包取舍
- **1-9**: 在背包对话框中丢弃对应物品
- **Enter**: 在背包对话框中拾取新物品（如果可以）
- **Escape**: 关闭背包对话框或关闭背包（在 INVENTORY 模式下）
- **F1**: 切换调试绘制
- **鼠标点击**: 在背包面板中点击按钮进行操作

## 注意事项

- 拾取默认进入普通区（unsafe）
- 普通区->安全区的移动需要灵气+读条（见灵气系统文档）
- 丢弃的物品会掉在玩家脚边，可以重新拾取
- GroundLoot 参与渲染和 y 排序，遮挡关系正确
- INVENTORY 模式下，所有游戏操作都被禁用，只允许 UI 操作
