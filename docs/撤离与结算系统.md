# 撤离与结算系统

## 概述

撤离与结算系统负责游戏倒计时、撤离点交互、玩家HP管理、游戏结算和重新开始机制。

## 核心组件

### 1. 全局倒计时 (SessionTimer.ts)
- **初始时间**: 12 分钟（720 秒）
- **显示**: HUD 左上角显示 mm:ss 格式
- **更新**: 每帧递减（仅在 `RUNNING` 状态下）
- **触发**: 当 `timer <= 0` 时，触发 `failExtraction("TIMEOUT")` 并进入结算

### 2. 撤离点 (ExtractionZone.ts)
- **位置**: 地图右侧 (1800, 400)
- **交互范围**: `radius = 36`
- **读条时间**: `channelSeconds = 15`
- **消耗灵气**: `costAura = 100`（成功时扣除）
- **渲染**: 扁平风格撤离圈，玩家进入范围时高亮（黄色描边）
- **撤离状态**: `extractState: 'IDLE' | 'EXTRACTING' | 'SUCCESS'`
- **交互机制**:
  - **自动开始**: 玩家进入撤离区域且 `aura >= 100` 且 `extractState === 'IDLE'` 时，自动开始撤离读条
  - **离开取消**: 玩家离开撤离区域时，立即取消撤离读条（进度重置为0），**不触发失败结算**
  - **重新进入**: 可以重新进入区域再次开始撤离读条
  - **区域内免伤**: 在撤离区域内，玩家不受敌人伤害
  - **提示显示**:
    - 在区域内且灵气不足：显示"灵气不足（当前X/需要100）"
    - 在区域内且灵气足够：自动开始撤离，不显示提示

### 3. 玩家 HP 系统
- **初始 HP**: 100
- **最大 HP**: 100
- **显示**: HUD 显示 HP（颜色随血量变化：>50% 绿色，>25% 黄色，<=25% 红色）
- **死亡**: HP <= 0 触发 `failExtraction("DEAD")`
- **免伤机制**: 在撤离区域内，`takeDamage()` 会检查是否在区域内，如果在区域内则忽略伤害

### 4. 结算流程
- **游戏阶段**: `gamePhase: "RUNNING" | "RESULT"`
- **进入 RESULT 时**:
  - 停止倒计时、停止交互
  - 结算物品：
    - `SUCCESS`: 保留 safe + unsafe
    - `FAIL`: 保留 safe，清空 unsafe
  - 显示结算 UI：
    - 成功/失败原因（SUCCESS / TIMEOUT / DEAD）
    - 带回物品列表（safe + (success?unsafe:[])）
    - 丢失物品列表（fail 时显示原 unsafe）
    - 按钮："重新开始"（重置玩家位置、清空地面掉落、重置 timer/aura/hp，背包按结算结果保留）

### 5. 输入优先级与冲突
- **GAME 模式**:
  - `E`: 采集 AuraNode（优先）> 拾取 GroundLoot
  - `I/Tab`: 打开/关闭背包
- **INVENTORY 模式**: 仅 UI 操作
- **CHANNELING 模式（撤离期间）**: 
  - `WASD`: 允许移动（躲避敌人）
  - `Esc`: 取消撤离（离开区域也会自动取消）
- **撤离取消逻辑**:
  - 离开撤离区域：重置状态，不触发失败结算
  - 按 Esc 取消：如果正在撤离，调用 `onLeaveZone()`（不触发失败结算）

## 核心函数说明

### onEnterZone()
**位置**: `src/game/Game.ts` (约第 530 行)
```typescript
private onEnterZone(): void {
  if (!this.extractionZone || this.gamePhase !== 'RUNNING') return;
  
  // 检查是否满足条件：灵气足够且状态为 IDLE
  if (this.extractState === 'IDLE' && this.aura.getCurrent() >= this.extractionZone.costAura) {
    this.extractState = 'EXTRACTING';
    this.extractProgress = 0;
    
    // 进入 CHANNELING 模式显示进度
    this.uiState.uiMode = 'CHANNELING';
    this.uiState.channelType = 'EXTRACT';
    this.uiState.channelProgress = 0;
  }
}
```
- 进入撤离区域时自动调用
- 检查灵气是否足够（>=100）且状态为 IDLE
- 自动开始撤离读条，不扣费（成功时扣）

### onLeaveZone()

### updateExtraction()
**位置**: `src/game/Game.ts` (约第 571 行)
```typescript
private updateExtraction(deltaTime: number): void {
  if (this.extractState !== 'EXTRACTING' || !this.extractionZone) return;
  
  // 检查玩家是否仍在区域内
  const isInZone = this.extractionZone.isPlayerInRange(this.player.x, this.player.y);
  
  if (!isInZone) {
    // 离开区域：取消撤离
    this.onLeaveZone();
    return;
  }
  
  // 更新进度
  this.extractProgress += deltaTime / 1000;
  this.uiState.channelProgress = Math.min(this.extractProgress / this.extractionZone.channelSeconds, 1);
  
  // 检查是否完成
  if (this.extractProgress >= this.extractionZone.channelSeconds) {
    // 读条完成，检查灵气是否足够
    if (!this.aura.canSpendAura(this.extractionZone.costAura)) {
      // 灵气不足，取消撤离
      this.extractState = 'IDLE';
      this.extractProgress = 0;
      this.uiState.uiMode = 'GAME';
      this.uiState.channelType = null;
      this.uiState.channelProgress = 0;
      return;
    }
    
    // 扣费并成功撤离
    this.aura.spendAura(this.extractionZone.costAura);
    this.extractState = 'SUCCESS';
    this.successExtraction();
  }
}
```
- 每帧更新撤离进度
- 检查玩家是否仍在区域内（离开则取消）
- 读条完成后检查灵气并扣费，然后成功撤离

### enterResult()
**位置**: `src/game/Game.ts` (约第 675 行)
```typescript
private enterResult(reason: 'SUCCESS' | 'TIMEOUT' | 'DEAD'): void {
  this.gamePhase = 'RESULT';
  this.sessionTimer.stop();
  
  // 保存结算前的物品状态（在清空之前）
  const safeItems = this.bag.getSafeItems();
  const unsafeItems = this.bag.getUnsafeItems();
  
  // 结算物品
  if (reason === 'SUCCESS') {
    // 成功：保留 safe + unsafe
    // 不需要操作，bag 保持原样
  } else {
    // 失败：保留 safe，清空 unsafe
    for (let i = unsafeItems.length - 1; i >= 0; i--) {
      this.bag.dropFromUnsafe(i);
    }
  }
  
  // 设置结算信息
  this.uiState.resultReason = reason;
  this.uiState.resultSafeItems = safeItems;
  this.uiState.resultUnsafeItems = reason === 'SUCCESS' ? unsafeItems : [];
  this.uiState.resultLostItems = reason === 'SUCCESS' ? [] : unsafeItems;
}
```
- 停止倒计时和交互
- 根据成功/失败结算物品
- 设置结算 UI 状态

### Player.takeDamage()
**位置**: `src/game/Player.ts` (约第 242 行)
```typescript
takeDamage(amount: number, extractionZone?: { isPlayerInRange: (x: number, y: number) => boolean }): void {
  // 如果提供了撤离区域，检查是否在区域内（区域内免伤）
  if (extractionZone && extractionZone.isPlayerInRange(this.x, this.y)) {
    return; // 区域内免伤
  }
  
  // 正常扣血
  this.hp = Math.max(0, this.hp - amount);
}
```
- 支持区域内免伤机制
- 如果提供 `extractionZone` 且在区域内，忽略伤害

## 技术细节

- **撤离状态管理**: 使用 `extractState` 跟踪撤离状态（IDLE/EXTRACTING/SUCCESS）
- **自动开始机制**: 在 `update()` 中每帧检查玩家是否在撤离区域内，自动开始/取消撤离
- **区域内免伤**: `Player.takeDamage()` 检查是否在撤离区域内，如果在则忽略伤害
- **结算物品保存**: 在清空 unsafe 之前保存物品列表，用于显示丢失物品
- **重新开始**: 重置玩家位置、HP、灵气、倒计时，清空地面掉落物，重新初始化地面掉落物

## 注意事项

- **撤离机制**: 进入区域自动开始，离开区域自动取消（不触发失败结算）
- **扣费时机**: 撤离成功时扣费（读条完成时），不是开始时扣费
- **区域内免伤**: 在撤离区域内不受敌人伤害
- **撤离期间移动**: 撤离读条期间可以移动躲避敌人
- **离开区域**: 离开撤离区域不会触发失败结算，只是取消撤离读条
- **结算时成功保留所有物品，失败只保留安全区物品**
- **重新开始时，背包按结算结果保留（成功保留所有，失败只保留安全区）**
