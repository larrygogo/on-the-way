# 改动总结：从等距 2.5D 改为横向卷轴 2.5D

## 改动文件列表

### 修改的文件
1. **src/game/Camera.ts** - 完全重写
   - 移除等距投影依赖
   - 改为简单的横向卷轴相机系统
   - `worldToScreen`: `sx = x - cameraX`, `sy = y - cameraY`
   - 主要跟随玩家 x（横向卷轴），y 可固定或轻微跟随

2. **src/game/Player.ts** - 重大修改
   - 坐标从 `(x, y, h)` 改为 `(x, y, z)`（z 暂时不用）
   - 深度键从 `x + y` 改为 `y`（按 y 值排序）
   - 添加 `WalkRect` 接口和 `setWalkRect()` 方法
   - 添加 `clampPosition()` 方法，限制在 walkRect 内
   - 阴影位置调整（在脚下，而非脚下+h）

3. **src/game/Renderer.ts** - 修改排序逻辑
   - 排序逻辑保持不变（按 depthKey 从小到大）
   - 但 depthKey 的含义改变：现在是 y 值
   - 注释更新：按 y 值排序，越靠下越在前

4. **src/game/Game.ts** - 更新初始化
   - 移除 Isometric 初始化
   - 使用 GroundBand 替代 TileMap
   - 设置玩家 walkRect

5. **src/game/Renderable.ts** - 更新注释
   - 更新深度键说明，明确按 y 值排序

### 新增的文件
1. **src/game/GroundBand.ts** - 地面带系统
   - 绘制可走区域（矩形/轻微梯形）
   - 显示上下边界线
   - 扁平风格配色

### 删除的文件
1. **src/game/Isometric.ts** - 不再需要等距投影
2. **src/game/TileMap.ts** - 改为 GroundBand

update(): void {
  if (this.followX) {
    // 主要跟随 x，使玩家位于屏幕中心
    this.cameraX = this.targetX - this.centerX;
  }
  
  if (this.followY) {
    // y 可轻微跟随（可选）
    this.cameraY = this.targetY - this.centerY;
  } else {
    // y 固定（不跟随）
    this.cameraY = 0;
  }
}
```

render(renderables: Renderable[], camera: Camera): void {
  // 按深度键排序（从小到大，y 值小的先绘制，y 值大的后绘制，实现遮挡）
  const sorted = [...renderables].sort((a, b) => a.getDepthKey() - b.getDepthKey());

  // 清空画布
  this.clear();

  // 依次渲染
  for (const renderable of sorted) {
    renderable.render(this.ctx, camera);
  }
}
```
