# 日志系统

## 概述

日志系统提供统一的日志管理功能，支持按模块和级别控制 console 输出，可以通过配置灵活控制日志显示。

## 功能特性

- ✅ **日志级别控制** - 支持 DEBUG、INFO、WARN、ERROR、NONE 五个级别
- ✅ **模块化日志** - 可以为不同模块设置不同的日志级别
- ✅ **配置驱动** - 通过 ConfigManager 统一管理日志配置
- ✅ **格式化输出** - 支持显示时间戳和模块名
- ✅ **运行时控制** - 可以在运行时动态调整日志级别

## 配置位置

日志配置在 `GameSettings` 的 `debug` 字段中：

```typescript
debug: {
  logEnabled: boolean;        // 是否启用日志
  logLevel: 'DEBUG' | 'INFO' | 'WARN' | 'ERROR' | 'NONE';  // 全局日志级别
  showTimestamp: boolean;     // 是否显示时间戳
  showModule: boolean;        // 是否显示模块名
  logModules: {               // 模块特定配置
    [module: string]: {
      enabled: boolean;
      level: 'DEBUG' | 'INFO' | 'WARN' | 'ERROR' | 'NONE';
    };
  };
}
```

## 使用方法

### 1. 基本使用

```typescript
import { logger } from '@/core/utils/Logger';

// 输出不同级别的日志
logger.debug('Game', '调试信息');
logger.info('Game', '普通信息');
logger.warn('Game', '警告信息');
logger.error('Game', '错误信息');
```

### 2. 创建模块日志器（推荐）

```typescript
import { createModuleLogger } from '@/core/utils/Logger';

const log = createModuleLogger('Game');

// 使用更简洁
log.debug('调试信息');
log.info('普通信息');
log.warn('警告信息');
log.error('错误信息');
```

### 3. 运行时调整日志级别

```typescript
import { logger, LogLevel } from '@/core/utils/Logger';

// 设置全局日志级别
logger.setLevel(LogLevel.DEBUG);

// 设置特定模块的日志级别
logger.setModuleLevel('Game', LogLevel.DEBUG, true);

// 启用/禁用日志
logger.setEnabled(false);
```

## 配置示例

### 示例 1：只显示错误和警告

```typescript
const configManager = ConfigManager.getInstance();
configManager.updateCategory('debug', {
  logEnabled: true,
  logLevel: 'WARN',  // 只显示 WARN 和 ERROR
  showTimestamp: false,
  showModule: true,
  logModules: {}
});
```

### 示例 2：为不同模块设置不同级别

```typescript
const configManager = ConfigManager.getInstance();
configManager.updateCategory('debug', {
  logEnabled: true,
  logLevel: 'INFO',  // 全局默认级别
  showTimestamp: true,
  showModule: true,
  logModules: {
    'Game': { enabled: true, level: 'DEBUG' },      // Game 模块显示所有日志
    'Renderer': { enabled: true, level: 'WARN' },   // Renderer 只显示警告和错误
    'ResourceManager': { enabled: false, level: 'INFO' }  // 禁用 ResourceManager 日志
  }
});
```

### 示例 3：完全禁用日志

```typescript
const configManager = ConfigManager.getInstance();
configManager.updateCategory('debug', {
  logEnabled: false,  // 禁用所有日志
  logLevel: 'NONE',
  showTimestamp: false,
  showModule: false,
  logModules: {}
});
```

## 日志级别说明

- **DEBUG** (0) - 调试信息，最详细，开发时使用
- **INFO** (1) - 普通信息，默认级别
- **WARN** (2) - 警告信息，需要注意但不影响运行
- **ERROR** (3) - 错误信息，需要立即处理
- **NONE** (4) - 不显示任何日志

## 输出格式

日志输出格式：
```
[时间戳] [模块名] [级别] 消息内容
```

示例：
```
[14:30:25.123] [Game] [INFO] 游戏启动成功
[14:30:25.456] [Renderer] [WARN] 渲染性能警告
[14:30:25.789] [Game] [ERROR] 加载资源失败
```

如果禁用时间戳或模块名，相应部分不会显示。

## 迁移指南

### 从 console 迁移到 Logger

**之前：**
```typescript
console.log('[Game] 游戏启动');
console.warn('[Game] 警告信息');
console.error('[Game] 错误信息');
```

**之后：**
```typescript
import { createModuleLogger } from '@/core/utils/Logger';

const log = createModuleLogger('Game');
log.info('游戏启动');
log.warn('警告信息');
log.error('错误信息');
```

## 最佳实践

1. **使用模块日志器** - 为每个模块创建专用的日志器
2. **合理使用级别** - 根据信息重要性选择合适的级别
3. **生产环境配置** - 生产环境建议设置为 WARN 或 ERROR
4. **开发环境配置** - 开发环境可以使用 DEBUG 级别
5. **模块特定配置** - 为性能敏感模块（如 Renderer）设置更高级别

## 配置持久化

日志配置会自动保存到 localStorage，下次启动时会自动加载。

## 注意事项

- 日志配置更改后立即生效，无需重启
- 禁用日志后，所有日志调用都会被跳过，性能影响最小
- 模块名区分大小写，建议使用一致的命名规范
