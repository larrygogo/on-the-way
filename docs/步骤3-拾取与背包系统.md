## 核心功能说明

### 一、物品系统
- **ItemType**: 只有两种：POTION(size=1) 和 EQUIPMENT(size=2)
- **ItemInstance**: 带唯一 id 的物品实例
- **GroundLoot**: 地面掉落实体，包含 item 与世界坐标 pos(x,y)，参与渲染和 y 排序

### 二、储物袋 Bag
- safeCap=2, unsafeCap=8
- 拾取默认进入 unsafe（普通区）
- 提供函数：
  - `usedSafe()`, `usedUnsafe()` - 查询已使用容量
  - `canAddSafe()`, `canAddUnsafe()` - 检查是否可以添加
  - `addSafe()`, `addUnsafe()` - 添加物品
  - `dropFromSafe()`, `dropFromUnsafe()` - 丢弃物品
  - `moveSafeToUnsafe()`, `moveUnsafeToSafe()` - 移动物品

### 三、交互拾取
- 每帧找玩家最近的可拾取物（距离<=pickupRadius=28）
- HUD 显示提示：按 E 拾取：<name>(占格x)
- 按 E：
  - 若普通区放得下：拾取成功（从地面移除，加入 bag.unsafe）
  - 若放不下：弹出取舍弹窗

### 四、取舍弹窗/背包UI
- 弹窗显示新物品信息与当前占用：安全 used/cap | 普通 used/cap
- 按钮A：丢弃新物品（关闭弹窗）
- 按钮B：打开背包取舍：
  - 显示普通区列表（名称/占格），每项有"丢弃"按钮
  - 玩家丢弃到能放下新物品后，提供一个"拾取新物品"按钮完成拾取

### 五、背包管理系统
- **UI 模式状态**:
  - `uiMode`: "GAME" | "INVENTORY"
  - 按 I 或 Tab 切换背包打开/关闭
  - INVENTORY 模式时：禁用玩家移动/攻击/拾取输入（只允许 UI 操作）
  - HUD 仍显示占用信息
- **背包面板（两栏）**:
  - 左栏：安全区列表
    - 显示 used/cap
    - 每个物品按钮：①移到普通区（免费）②丢弃
  - 右栏：普通区列表
    - 显示 used/cap
    - 每个物品按钮：①移到安全区（需要灵气+读条，Step 4 实现）②丢弃
- **丢弃规则**:
  - 安全区/普通区都可丢弃
  - 丢弃后在玩家脚边生成 GroundLoot（带轻微随机偏移），并从背包移除
  - 生成的 GroundLoot 可再次拾取

### 六、交互冲突处理
- INVENTORY 打开时，禁止 E 拾取提示与拾取执行（避免 UI 与交互冲突）
- 关闭背包回到 GAME 后恢复正常

## 按键说明

- **W/A/S/D**: 移动玩家
- **E**: 拾取物品（靠近掉落物时，仅在 GAME 模式下）
- **I/Tab**: 打开/关闭背包
- **A**: 在取舍弹窗中丢弃新物品
- **B**: 在取舍弹窗中打开背包取舍
- **1-9**: 在背包对话框中丢弃对应物品
- **Enter**: 在背包对话框中拾取新物品（如果可以）
- **Escape**: 关闭背包对话框或关闭背包（在 INVENTORY 模式下）
- **F1**: 切换调试绘制
- **鼠标点击**: 在背包面板中点击按钮进行操作

## 注意事项

- 拾取默认进入普通区（unsafe）
- 普通区->安全区的移动需要灵气+读条（Step 4 实现）
- 丢弃的物品会掉在玩家脚边，可以重新拾取
- GroundLoot 参与渲染和 y 排序，遮挡关系正确
- INVENTORY 模式下，所有游戏操作都被禁用，只允许 UI 操作
