# 碰撞系统

## 概述

碰撞系统负责处理玩家与障碍物之间的碰撞检测和响应，实现滑墙效果，确保玩家无法穿过障碍物。

## 核心组件

### 1. 障碍物数据结构 (Obstacle.ts)
- **pos(x,y)**: 障碍物位置（世界坐标）
- **footprint(w,h)**: 脚底碰撞盒（用于碰撞检测）
- **visual(w,h)**: 视觉大小（用于绘制）
- **sortOffset**: 排序偏移（用于调整渲染顺序）

### 2. 碰撞检测工具 (Collision.ts)
- **AABB 碰撞检测**: 轴对齐边界框碰撞检测
- **核心方法**:
  - `toRect()` - 将实体转换为矩形
  - `rectsIntersect()` - AABB 碰撞检测
  - `rectsIntersectX()` / `rectsIntersectY()` - 轴向碰撞检测

### 3. 玩家碰撞处理 (Player.ts)
- **footprint**: 玩家脚底碰撞盒（16x16）
- **axis-separate 移动**: 先处理 x 方向，再处理 y 方向
- **滑墙效果**: 一个方向被阻挡时，另一个方向仍可移动

## 核心函数位置

### 1. toRect
**文件**: `src/game/Collision.ts`
**行号**: 约第 15-21 行
```typescript
static toRect(x: number, y: number, width: number, height: number): Rect {
  return {
    x: x - width / 2,
    y: y - height / 2,
    width: width,
    height: height
  };
}
```
- 将实体位置和尺寸转换为矩形（用于碰撞检测）

### 2. rectsIntersect
**文件**: `src/game/Collision.ts`
**行号**: 约第 28-35 行
```typescript
static rectsIntersect(rect1: Rect, rect2: Rect): boolean {
  return (
    rect1.x < rect2.x + rect2.width &&
    rect1.x + rect1.width > rect2.x &&
    rect1.y < rect2.y + rect2.height &&
    rect1.y + rect1.height > rect2.y
  );
}
```
- AABB 碰撞检测（轴对齐边界框）

### 3. moveWithCollisions
**文件**: `src/game/Player.ts`
**行号**: 约第 85-110 行
```typescript
private moveWithCollisions(dx: number, dy: number): void {
  const originalX = this.x;
  const originalY = this.y;

  // 先处理 x 方向移动
  if (dx !== 0) {
    this.x += dx * this.speed;
    const newRect = this.getFootprintRect();
    if (this.checkCollision(newRect)) {
      // 碰撞了，回退 x
      this.x = originalX;
    }
  }

  // 再处理 y 方向移动
  if (dy !== 0) {
    this.y += dy * this.speed;
    const newRect = this.getFootprintRect();
    if (this.checkCollision(newRect)) {
      // 碰撞了，回退 y
      this.y = originalY;
    }
  }

  // 限制在可走区域内
  this.clampPosition();
}
```
- axis-separate 移动（先处理 dx 再处理 dy）
- 实现滑墙效果（一个方向被阻挡时，另一个方向仍可移动）

### 4. sortRenderItems
**文件**: `src/game/Renderer.ts`
**行号**: 约第 78-79 行
```typescript
const sorted = [...renderables].sort((a, b) => a.getDepthKey() - b.getDepthKey());
```
- 按 `(y + sortOffset)` 排序（在 `getDepthKey()` 中实现）
- 越靠下（y + sortOffset 值大）的实体越后绘制，实现遮挡

## 功能说明

### 1. 碰撞检测
- 使用 AABB（轴对齐边界框）碰撞检测
- 只使用 footprint 参与碰撞（视觉大小不影响碰撞）
- axis-separate 处理：先处理 x 方向，再处理 y 方向
- 实现滑墙效果：一个方向被阻挡时，另一个方向仍可移动

### 2. 渲染遮挡
- 玩家和障碍物放入统一 render list
- 按 `(y + sortOffset)` 排序绘制
- 保证玩家在障碍物前后遮挡正确

### 3. 调试开关
- 按 F1 键切换调试绘制
- 开启时显示：
  - 玩家 footprint（绿色半透明矩形）
  - 障碍物 footprint（红色半透明矩形）

## 测试步骤

1. 运行 `npm run dev` 启动开发服务器
2. 在浏览器中打开页面
3. 使用 WASD 键移动玩家：
   - 尝试靠近障碍物，应该被阻挡
   - 尝试贴着障碍物移动，应该可以滑动
   - 尝试绕障碍物走一圈，不应该穿模
4. 按 F1 键切换调试绘制：
   - 查看玩家 footprint（绿色）
   - 查看障碍物 footprint（红色）
   - 确认 footprint 大小与碰撞检测一致
5. 测试遮挡：
   - 移动到障碍物前方（y 值小），玩家应该遮挡障碍物
   - 移动到障碍物后方（y 值大），障碍物应该遮挡玩家
6. 测试移动限制：
   - 尝试移动到地面带外，应该被限制

## 注意事项

- 碰撞检测只使用 footprint，视觉大小不影响碰撞
- axis-separate 处理顺序：先 x 后 y
- 排序使用 `(y + sortOffset)`，可以通过 sortOffset 调整渲染顺序
- 调试绘制使用半透明矩形，便于调参
